# 4. Simulation Study
We conducted a simulation study to compare the estimation accuracy of three modeling approaches. Two simulation scenarios were considered: (1) Independent scenario (2) Spatial scenario. In the Independent scenario, the true area-specific effects were generated independently across areas. In contrast, the Spatial scenario assumed that the true area-specific effects are spatillay dependent. 

For each scenario, we generated datasets for three data lengths (1-year, 3-year, and 7-year), with 20 datasets for each data length. First, let me introduce the code for Independent scenario.
```r
# Generating 1_year data

simulation_data4_emp = death247_2021
simulation_data4_emp[,3] = NA
simulation_data4_emp = simulation_data4_emp %>% arrange(region)
simulation_data4_emp$num <- as.numeric(gsub("_", "", simulation_data4_emp$zone_ymd))
simulation_data4_emp$strata <- as.factor(simulation_data4_emp$num)
simulation_data4_emp$strata <- as.numeric(simulation_data4_emp$strata)
simulation_data4_emp = simulation_data4_emp %>% arrange(strata)
death247_2021$strata <- simulation_data4_emp$strata

kappa = rep(NA, length(unique(death247_2021$zone_ymd)))
for (i in 1:length(unique(death247_2021$strata))) {
  kappa[i] <- mean(subset(death247_2021, strata == i)$count)
}

```
