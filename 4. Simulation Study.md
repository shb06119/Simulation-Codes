# 4. Simulation Study
We conduct a simulation study to compare the estimation accuracy of three modeling approaches. Two simulation scenarios are considered: (1) Independent scenario (2) Spatial scenario. In the Independent scenario, the true area-specific effects are generated independently across areas. In contrast, the Spatial scenario assumes that the true area-specific effects are spatillay dependent.

For each scenario, we generate datasets for three data lengths (1-year, 3-year, and 7-year), with 20 datasets for each data length.
```r
# Fixed effects
beta1 = 0.5; beta2 = -0.01

# Independent scenario assumes that the true effects are independent.
set.seed(100)
u1i_sample = rnorm(77, mean = 0, sd = 1)

# Spatial scenario assumes that the true effects are spatially dependent. (SAR model)
adjmatrix <- data.frame(fread("/Users/nani13143553/Desktop/Final Simulation/adjacent matrix.csv", header = TRUE)[,-1])
adjmatrix <- adjmatrix[c(1:25, 50:59, 76:117), c(1:25, 50:59, 76:117)]
W <- as.matrix(adjmatrix)
lw <- mat2listw(W, style = "W")
n <- nrow(W)
rho <- 0.9
sigma2 <- 0.1 ############################
set.seed(100)
eps <- rnorm(n, sd = sigma2)
u1i_sample  <- as.numeric(invIrW(lw, rho) %*% eps)
```

  matrix_list_77[[i]] <- region_mat

  subdata <- subset(regiondat, strata == i + (k-1)*84)
  kappaij <- log(kappa[i + (k-1)*84])
  for (j in 1:nrow(subdata)) {
    matrix_list_77[[k]][i,j] <- exp(kappaij + (beta1 + u1i_sample[k])*subdata[j, 4] + beta2*subdata[j, 13])
  }
 }

  for (j in 1:84) {
    for (k in 1:5) {
     Y_list_77[[i]][j, k] <- rpois(1, matrix_list_77[[i]][j, k])
    }
  }
}
